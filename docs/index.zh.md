# Focalcrest 射频测试指南

适用于搭载 AP6256 模块的 Focalcrest AZ 系列产品的 WiFi / 蓝牙定频射频测试。所有产品测试步骤相同，只是测试镜像不同。

**请按顺序操作：**

1. **[确认产品](products.md)** —— 以及对应的测试镜像。
2. **[烧录测试镜像](flashing.md)** —— Windows 客户端，使用 Rockchip Flash Tool。
3. **[WiFi / 蓝牙射频测试](wifibt-test.md)** —— 通过 ADB 执行 `wl` / `hcitool` 定频测试。

!!! note
    必须先烧录镜像，再进行任何测试。
