# Focalcrest RF Test Guide

WiFi / Bluetooth fixed-frequency RF test for Focalcrest AZ products with the AP6256 module. Every product uses the same procedure; only the test image differs.

**Do it in order:**

1. **[Find your product](products.md)** — and its test image.
2. **[Flash the test image](flashing.md)** — Windows PC, Rockchip Flash Tool.
3. **[WiFi / Bluetooth RF test](wifibt-test.md)** — `wl` / `hcitool` fixed-frequency tests over ADB.

!!! note
    The device must be flashed before running any test.
