# AZ08 WiFi / Bluetooth Test

Guides for flashing and RF-testing the AZ08 (RK3576S + AP6256) module.

**Do it in order:**

1. **[Flash the device image](flashing.md)** — Windows client, Rockchip Flash Tool.
2. **[WiFi / Bluetooth RF test](wifibt-test.md)** — `wl` / `hcitool` fixed-frequency tests over ADB.

!!! note
    The device must be flashed before running any test.
